# Верстак — сайт-портфолио независимой digital-студии

Полноценный статический сайт-портфолио: тёмный графит + электрический лайм,
редакционная типографика (Unbounded / Manrope / JetBrains Mono), интерактивный
hero-объект на canvas и три **полностью интерактивных демонстрационных продукта**
с собственными дизайн-системами.

Без сборки и зависимостей: чистый HTML5 + CSS3 + JavaScript.
Все шрифты и изображения лежат локально — сайт работает офлайн.

---

## Быстрый старт

### Вариант 1 — просто открыть
Откройте `index.html` двойным кликом. Сайт полностью работает без сервера
(все пути относительные).

### Вариант 2 — локальный сервер (рекомендуется)
```bash
cd verstak
python3 -m http.server 8000
# откройте http://localhost:8000
```
или `npx serve .` — любой статический сервер подойдёт.

## Что интерактивно

**Главная**
- «Жидкий» шейдерный фон-аврора в hero и секции контактов: медленно текущие
  лаймовые потоки по графиту на WebGL (доменно-деформированный шум), реагирует
  на курсор. Пауза вне вьюпорта и в фоновой вкладке; при отсутствии WebGL или
  включённом «меньше движения» — статичный кадр либо просто скрытие слоя.
- Живая canvas-система модулей в hero (реагирует на курсор, пауза вне вьюпорта).
- Раскрывающийся индекс услуг с мини-моками интерфейсов для каждого направления.
- Таймлайн процесса с прогрессом при прокрутке.
- Плавающие меню на мобильных, wipe-переходы между страницами.
- Форма заявки с валидацией и **честным демо-режимом** (см. ниже).

**FLOWDESK** (`projects/flowdesk.html`)
- Дашборд с KPI, графиком визитов и статусами — всё считается из данных.
- Таблица заявок: поиск, фильтры по статусам, приоритеты.
- Карточка заявки: смена статуса, редактирование, история клиента.
- Создание заявки (модальная форма) — появляется в таблице, календаре и KPI.
- Календарь месяца: навигация, клик по дню → создание записи, клик по событию → карточка.
- Карточки клиентов с историей заявок и техникой.
- Уведомления с непрочитанными, тосты действий.

**TENDERTRACE** (`projects/tendertrace.html`)
- Лента из 20 тестовых закупок с оценкой релевантности (кольцевые индикаторы).
- Поиск по названию/организации/номеру, фильтры по регионам и категориям,
  порог релевантности, сроку подачи заявок, 4 варианта сортировки.
- Избранное (звезда в списке и карточке, счётчик, режим «только избранное»).
- Карточка закупки: описание, требования, документы, «отслеживать».
- Аналитика выборки: распределение по категориям и дедлайнам — пересчитывается при фильтрации.

**FRAMEPORT** (`projects/frameport.html`)
- Editorial-галерея из 14 сгенерированных фотографий, 4 категории + избранное.
- Лайтбокс: стрелки, клавиатура (←/→/Esc), свайп, избранное внутри.
- Отбор до 15 кадров, плавающая панель «Отправить выбор фотографу».
- Статусы обработки, карточка «Получение материалов», история заказов.

## Контакты и форма заявки — самое важное

Всё меняется в **одном файле `js/config.js`**:

```js
window.VERSTAK_CONFIG = {
  telegramHandle: "angcorupt",           // ваш Telegram без @
  telegramUrl: "https://t.me/angcorupt", // ссылка
  email: "gorkaffg@gmail.com",           // ваша почта
  formEndpoint: "",                      // приёмщик заявок (см. ниже)
};
```

Эти значения автоматически подставляются в блок «Контакты», мобильное меню
и генерируют готовые ссылки «написать в Telegram / email» с текстом заявки.

### Подключение реальной отправки формы
Сейчас форма **не притворяется отправленной**: она показывает честное сообщение
о демо-режиме и предлагает отправить текст напрямую в Telegram или на email.

Чтобы включить реальную отправку, укажите в `config.js`:
```js
formEndpoint: "https://formspree.io/f/ВАШ_ID",
```
Форма отправит `POST` с JSON: `{ name, contact, type, message, meta }`.

Другие варианты приёмщика: собственный API, серверный бот Telegram
(прокси, пересылающий заявку в чат), Netlify Forms (добавьте атрибуты
`netlify` к форме в `index.html`).

## Публикация сайта

Сайт статический — подходит любой хостинг без сборки.

**GitHub Pages**
1. Создайте репозиторий, загрузите содержимое папки `verstak/` в корень (или в ветку `gh-pages`).
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по `https://username.github.io/repo/`.

**Netlify (проще всего)**
1. Откройте https://app.netlify.com/drop
2. Перетащите папку `verstak/` в окно — сайт опубликован.

**Vercel**
1. `npx vercel` в папке проекта → подтверждите настройки (framework: Other).

**Обычный хостинг**
Загрузите содержимое папки по FTP/SSH в корень сайта. Никакой сборки не нужно.

> Контакты (`@angcorupt`, `gorkaffg@gmail.com`) уже внесены в `js/config.js`.
> Перед публикацией при желании замените домен в мета-теге `og:url`/`canonical`
> в `index.html`.

## Замечания по контенту

- Три демонстрационных проекта — **концептуальные демонстрации** с тестовыми
  данными. Это указано на сайте (в секции проектов и в шапках демо) и их
  следует воспринимать как витрину возможностей, а не как коммерческие кейсы.
- Фотографии в FRAMEPORT сгенерированы специально для демо (свободны от прав
  третьих лиц). Данные FLOWDESK/TENDERTRACE — вымышленные, но реалистичные.
- Шрифты Unbounded, Manrope, JetBrains Mono распространяются по лицензии
  SIL Open Font License и лежат локально в `assets/fonts/`.

## Поддержка браузеров
Chrome / Edge / Firefox / Safari последних версий. Используются CSS Grid,
`clamp()`, IntersectionObserver, canvas, WebGL — без полифилов. «Жидкий» фон
корректно отключается там, где WebGL недоступен. Есть поддержка
`prefers-reduced-motion`: пользователю с включённым «меньше движения»
анимации отключаются, шейдер показывает один статичный кадр.
